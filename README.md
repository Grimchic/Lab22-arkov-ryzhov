## Тема

Dictionary и HashSet в C#.

## Что реализовано

- хранение исключений в HashSet;
- добавление и удаление исключений;
- подготовка и разделение текста на слова;
- подсчёт частот в Dictionary;
- вывод общей статистики;
- безопасный поиск слова через TryGetValue.

## Короткие ответы

1. Что должно быть уникальным в Dictionary и в HashSet?

Ответ: В Dictionary уникальными являются ключи — двух одинаковых ключей быть не может, а значения могут повторяться. В HashSet уникальным является каждый элемент множества.

2. Чем отличается повторное добавление в HashSet от Dictionary.Add() с существующим ключом?

Ответ: Повторный Add() в HashSet просто возвращает false — элемент не добавляется повторно, исключение не возникает, Count не меняется. Dictionary.Add() при существующем ключе выбрасывает исключение, поэтому новое значение ключу присваивают через квадратные скобки.

3. Почему для поиска по неизвестному ключу удобно использовать TryGetValue()?

Ответ:  Чтение словаря по отсутствующему ключу приводит к исключению, а TryGetValue() в его месте спокойно возвращает false, и это можно обработать условием. К тому же метод за один вызов даёт и факт наличия ключа, и само значение — проверять наличие по величине значения не нужно.
